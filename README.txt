제주하루 웹사이트 사용 방법

1. 인터넷이 연결된 상태에서 index.html 파일을 더블클릭합니다.
2. 크롬 또는 사파리에서 바로 실행됩니다.
3. 코드를 수정하려면 VS Code에서 '제주하루_웹사이트' 폴더를 엽니다.

파일 구성
- index.html : 화면 구조
- styles.css : 디자인
- data.js : 제주 관광지 30곳 정보와 좌표
- app.js : 지도, 선택, 일정 미리보기 기능
- assets/jeju-haru-preview.png : 대표 이미지

현재 지도와 관광지 마커는 API 키 없이 작동합니다.
지도 표시에는 인터넷 연결이 필요합니다.
일정 미리보기의 이동시간과 경로선은 UI 확인용 임시 결과입니다.
추후 경로·일정 담당자의 실제 알고리즘과 네이버 Directions API 결과로 교체하면 됩니다.
